
# Contributing to MarketingOps Kit

Thanks for your interest in contributing.

## Ways to Contribute

- Suggest a new marketing workflow
- Improve an existing skill
- Report factual or methodological errors
- Add test scenarios
- Improve templates and documentation

## Contribution Standards

All contributions should:

1. Distinguish facts from hypotheses.
2. Avoid fabricated research or metrics.
3. Explain the strategic purpose.
4. Include practical quality checks.
5. Respect copyright and source attribution.

## New Skill Structure

Each new skill should ideally include:

- SKILL.md
- templates/
- examples/
- tests/

## Pull Requests

Explain:
- What changed
- Why the change matters
- How it was tested
- Known limitations

AI-generated contributions must be
reviewed for accuracy before submission.
